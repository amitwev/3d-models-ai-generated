# Mobula7 – שלט ESP32 עם אייפון

רחפן Mobula7 עם בקר Crazybee F4FR, שנשלט מהאייפון דרך שני לוחות ESP32.

- דף העבודה (צ'קליסט): `phase1-guide.html`
- מסמך התכנון: `../docs/superpowers/specs/2026-10-16-mobula7-esp32-remote-phase1-design.md`

## 0. משיכת הקבצים עם git

מהתיקייה של הריפו:

```bash
git fetch origin claude/serene-meitner-7wc24f
git checkout claude/serene-meitner-7wc24f
git pull
```

כדי שהספרייה ב-Arduino תתעדכן מעצמה אחרי כל `git pull`, מקשרים אותה לריפו במקום להעתיק אותה. מריצים פעם אחת, מתיקיית הריפו:

```bash
rm -rf ~/Documents/Arduino/libraries/Mobula7Link
ln -s "$PWD/mobula7-remote/firmware/Mobula7Link" ~/Documents/Arduino/libraries/Mobula7Link
```

## 1. התקנה חד-פעמית ב-Arduino IDE

1. מתקינים את **Arduino IDE 2** מהכתובת arduino.cc/en/software.
2. מוסיפים תמיכה בלוחות ESP32:
   - פותחים **Arduino IDE → Settings** (במק: Arduino IDE → Settings…).
   - בשדה **Additional boards manager URLs** מדביקים:
     `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   - פותחים את **Boards Manager** (האייקון השני בסרגל השמאלי), מחפשים `esp32` ומתקינים את **esp32 by Espressif Systems**, גרסה **3.x**.
3. מתקינים את הספרייה של הפרויקט:
   - מקשרים אותה לריפו (ראו סעיף 0), או מעתיקים את התיקייה `firmware/Mobula7Link` אל `~/Documents/Arduino/libraries/`.
   - אם התיקייה `libraries` לא קיימת, יוצרים אותה.
   - **סוגרים ופותחים מחדש** את Arduino IDE.

## 2. צריבת ה-ESP32 של הרחפן (RX)

1. מחברים את ה-ESP32 למחשב בכבל USB-C.
2. **File → Open** ופותחים את `firmware/mobula7_rx/mobula7_rx.ino`.
3. בתפריט הבחירה שלמעלה בוחרים את הלוח **ESP32 Dev Module** ואת הפורט. במק הפורט נראה בערך כך: `/dev/cu.usbserial-…` או `/dev/cu.wchusbserial…`.
4. לוחצים על החץ **Upload** (→).
   - אם הצריבה נתקעת על `Connecting.....`, לוחצים על כפתור **BOOT** ב-ESP32 ומחזיקים אותו עד שמופיעים אחוזים.
5. בסוף אמורה להופיע ההודעה `Hard resetting via RTS pin...`.

**בדיקה שהצריבה עבדה:** פותחים את **Tools → Serial Monitor** ובוחרים בפינה **115200 baud**. כל שנייה צריכה להופיע שורה כמו:

```
link=1 arm=1000 thr=1000 roll=1437
```

המספר אחרי `roll` משתנה כל שנייה, בין 1000 ל-2000. אם לא מופיעה שום שורה, לוחצים על כפתור **EN** (Reset) ב-ESP32.

### מצב בדיקה (RX_SELFTEST)

בשורה 13 בקובץ כתוב `#define RX_SELFTEST 0` (מצב רגיל). כדי לעבור למצב בדיקה משנים ל-`1`. במצב הזה ה-ESP32 לא מקשיב לשלט. הוא רק מזיז לאט את ערוץ ה-Roll הלוך וחזור, וכך אפשר לבדוק את החיבור לבקר הטיסה. ARM והגז נשארים כל הזמן במצב בטוח (1000).

אחרי הבדיקה מחזירים ל-`0` וצורבים שוב.

## 3. חיבור ה-ESP32 לרחפן

| ESP32 | Crazybee F4FR V2.0 | מתי |
| --- | --- | --- |
| **D17** | פד **R2** (ליד ה-USB) | משלב 2 |
| **GND** | פד המינוס של הסוללה (חוט שחור עבה) | משלב 2 |
| **VIN** | פד הפלוס של הסוללה (חוט אדום עבה) | רק בשלב 5 |

- **לא** מחברים ל-`3V3`, ו**לא** מחברים ל-`VN`. VN הוא פין אחר לגמרי (GPIO39).
- כשה-ESP32 מחובר ב-USB למחשב, **לא מחברים את VIN**. מספיקים GND ו-D17.

## 4. השלט (TX)

### התקנה נוספת, פעם אחת

1. ב-Arduino IDE פותחים **Library Manager** (האייקון השלישי בסרגל השמאלי).
2. מחפשים `WebSockets`.
3. מתקינים את **WebSockets by Markus Sattler**.

### חיבור הכפתורים

כל כפתור מחובר בשני חוטים: אחד לפין ואחד ל-GND. לא משנה איזו רגל של הכפתור מחוברת לאיזה חוט.

| כפתור | ESP32 |
| --- | --- |
| **ARM** | `D25` ו-`GND` |
| **KILL** | `D26` ו-`GND` |

### צריבה

1. פותחים את `firmware/mobula7_tx/mobula7_tx.ino`.
2. הלוח: **ESP32 Dev Module**, מהירות העלאה (Upload Speed): **115200**.
3. בוחרים את הפורט של ה-ESP32 של **השלט** ולוחצים Upload.

ב-Serial Monitor, במהירות 115200, אמורה להופיע ההודעה:
```
mobula7_tx: Wi-Fi "Mobula7-Remote", open http://192.168.4.1
```
אחריה מופיעה פעם בשנייה שורת מצב, למשל `phone=0 arm_btn=0 kill_btn=0 armed=0 killed=1 ...`.

### חיבור האייפון

1. **הגדרות → Wi-Fi**, ומתחברים לרשת **Mobula7-Remote** עם הסיסמה **mobula7fly**.
   - אם iOS שואל אם להישאר ברשת בלי אינטרנט, עונים **כן**.
2. ב-Safari נכנסים ל-**http://192.168.4.1** ומסובבים את הטלפון לרוחב.
3. מקל שמאלי: למעלה ולמטה זה גז, והוא נשאר במקום כשעוזבים. ימינה ושמאלה זה סיבוב.
4. מקל ימני: הטיה. הוא חוזר למרכז כשעוזבים.

המקלות "צפים": במקום שבו נוגעים זה המרכז, והערך משתנה רק כשגוררים את האצבע.

### חימוש ו-KILL

- **חימוש:** מחזיקים את **ARM** חצי שנייה כשהגז למטה. אין כפתור חימוש בטלפון.
- **KILL:** לוחצים על **KILL**, והמנועים נעצרים מיד.
- **חימוש מחדש אחרי KILL:** משחררים את כל הכפתורים, ואז לוחצים שוב על ARM.

הרחפן מתנתק מעצמו בכל אחד מהמקרים האלה:
- הטלפון ננעל;
- יוצאים מ-Safari;
- השלט כבה.

## 5. מה ה-LED הכחול ב-ESP32 של השלט אומר

| LED | משמעות |
| --- | --- |
| כבוי | אין טלפון מחובר |
| הבהוב איטי (פעם בשנייה) | טלפון מחובר, הרחפן לא חמוש |
| הבהוב מהיר | KILL פעיל, או כיול אופק |
| דולק קבוע | **חמוש** |

## 6. מה ה-LED הכחול ב-ESP32 של הרחפן אומר

| LED | משמעות |
| --- | --- |
| דולק קבוע | יש קשר לשלט, או שהלוח במצב בדיקה |
| מהבהב מהר | אין קשר לשלט. הרחפן מקבל "נעול, גז אפס" |
