להחזיר את ה-Mobula7 לאוויר

שלב 1: אב-טיפוס על השולחן, לפני שמדפיסים. הרחפן מקבל פקודות מ-ESP32, והאייפון משמש כשלט. סמן את השלבים כאן תוך כדי עבודה. הסימונים נשמרים רק בדפדפן הזה.

שלב 1 מצליח כש: הרחפן מרחף נמוך בחדר עם ה-ESP32 עליו, נשלט ממקלות במסך האייפון, ו-KILL או כל ניתוק עוצרים את המנועים מיד.

✓ לוח חי, ג'יירו תקין ✓ גיבוי נשמר ✓ 4 מנועים חדשים 19000KV, מוגבלים ל-80% ✓ כיווני המנועים תוקנו ! כיול אופק: לפני טיסה ✓ סוללות טעונות: 2×450, ~8×300 ! רגולטור לא מזוהה, הסיכון מקובל
החלטה: לא מצאנו את סימון הרגולטור, וממשיכים בכל זאת. אם ה-ESP32 יישרף מהזנת 2S, נתמודד עם זה אז. כדאי להציץ בצד האחורי של הלוח. אם כתוב שם AMS1117, הכול בסדר.

איך זה מחובר

הטלפון לא צריך אינטרנט ולא צריך אפליקציה. מתחברים לרשת ה-Wi-Fi של השלט ופותחים את הכתובת בדפדפן. כפתורי ARM ו-KILL מחוברים ישירות ל-ESP32, כך שהם עובדים גם אם הטלפון נתקע.

חיווט ה-ESP32 לרחפן

ESP32 שעל הרחפןCrazybeeמתי
TX2 / GPIO17פד R2, ליד ה-USBמשלב 2
GNDפד המינוס של הסוללה (חוט שחור עבה)משלב 2
VIN, בפינה ליד ה-USB, צמוד ל-GNDפד הפלוס של הסוללה (חוט אדום עבה)רק בשלב 5

לא 3V3 ולא VN. 3V3 הוא יציאה של 3.3V, ו-8V שם שורפים את ה-ESP32 מיד. VN הוא קיצור של GPIO39, פין קלט, ולא מתח. הפין הנכון כתוב VIN, והוא נמצא בסוף אותה שורה של VN, ליד ה-USB.

על השולחן: כשה-ESP32 מחובר ב-USB למחשב, מחברים לרחפן רק GND ו-TX, בלי VIN. כך לא נכנסים לו שני מקורות מתח בבת אחת.

על הלוח שלך הפין של GPIO17 מסומן D17 (בלוחות אחרים TX2). מלחימים ל-R2: מורחים קצת פלקס, מבדילים את הפד ואת קצה החוט, ומצמידים לשנייה אחת. משתמשים בחוט דק, ומדביקים אותו ללוח בסרט כדי שמשיכה לא תתלוש את הפד. נזהרים לא לגשר בין R2 ל-T2.

לא נוגעים ב: חוטי המצלמה הישנה (שחור, אדום וכחול בקצה), החוט הירוק, אנטנת המקלט (חוט שחור) והבאזר.

סוללות

תמיד זוג זהה

הצמה מחברת שתי סוללות בטור (2S). מחברים לה 300+300 או 450+450, ואף פעם לא ערבוב. אם מערבבים, הסוללה הקטנה מתרוקנת יתר על המידה.

לטיסות עם ESP32: זוג 300

זוג 300 שוקל כ-16 גרם, וזוג 450 כ-24 גרם. עם ה-ESP32 על הרחפן כל גרם חשוב, לכן מתחילים בזוג 300.

לפני כל חיבור

בודקים שהסוללה לא נפוחה. סוללה נפוחה לא משתמשים בה. נוחתים כש-Betaflight מתריע (3.2V לתא).

כללי בטיחות שהקוד מבטיח

מה קורהמה הרחפן עושה
מחברים סוללהלא חמוש. אין דרך להתחמש בלי לחיצה על ARM.
החזקת ARM חצי שנייהמתחמש, אבל רק אם הגז במסך נמוך והטלפון מחובר.
לחיצה על KILLהמנועים נעצרים מיד. כדי להתחמש שוב צריך לשחרר את KILL וללחוץ על ARM.
הטלפון מתנתק יותר מ-0.3 שנייהכמו KILL.
השלט מתנתק יותר מ-0.15 שנייהה-ESP32 שעל הרחפן שולח "בטל חימוש", והמנועים נעצרים מיד.
הקשר חוזרנשאר לא חמוש עד לחיצה חדשה על ARM.
ה-ESP32 שעל הרחפן עצמו מתה-failsafe של Betaflight עוצר את המנועים, אחרי השהיה קצרה.

מצב הטיסה תמיד Angle: הרחפן מתיישר לבד כשעוזבים את המקל הימני. המקל השמאלי הוא גז וסיבוב, והימני הטיה (Mode 2).

פקודת Betaflight

מדביקים בלשונית CLI בשלב 2, לא לפני. הפקודה מעבירה את UART2 לקבלת פקודות מה-ESP32, מכבה את המקלט הפנימי, הופכת את ARM כך שיפעל רק כשהערוץ גבוה, מגדירה עצירת מנועים בניתוק, ומחזירה את הצפצוף כשהקשר אובד.

feature RX_SERIAL
serial 0 0 115200 57600 0 115200
serial 1 64 115200 57600 0 115200
set serialrx_provider = IBUS
map AETR1234
aux 0 0 0 1700 2100 0 0
aux 1 1 1 900 1300 0 0
aux 2 13 2 1700 2100 0 0
set failsafe_procedure = DROP
set failsafe_delay = 2
set motor_output_limit = 80
set yaw_motors_reversed = ON
beeper RX_LOST
beeper RX_LOST_LANDING
save

מדביקים שורה אחת בכל פעם ולוחצים Enter. שדה הפקודה של Betaflight מחבר הדבקה של כמה שורות לשורה אחת, והפקודה נכשלת.

אחרי save הלוח מאתחל את עצמו ומתנתק לרגע. זה תקין.
